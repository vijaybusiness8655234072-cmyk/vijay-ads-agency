# Vijay Ads Agency — From-scratch frontend

A responsive recreation of the supplied BrandWitty page structure and visual language, adapted for Vijay Ads Agency.

## Stack
- React + Vite
- Vanilla CSS
- Framer Motion
- Lucide React

## Install and run
From the project root:
```bash
npm run install:all
npm run dev
```

## Production build
```bash
npm run build
```

All photography areas are intentionally blank placeholders. Add your JPG files under `client/public/images/` later and replace the placeholder components in `client/src/App.jsx`.
